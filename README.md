## 🚀 Featured projects

### [CodeGuardian AI](https://github.com/DhyanMehta/Code-Guardian) · Multi-agent pull request review

Built a LangGraph workflow that runs four specialist reviews in parallel and combines their findings into a single GitHub pull request report. Added PostgreSQL checkpoints to recover completed agent outputs after an interruption in a test run.

`LangGraph` `FastAPI` `PostgreSQL` `Groq` `ChromaDB`

### [AcadeX](https://github.com/DhyanMehta/AcadeX) · Explainable academic risk detection

Integrated our team’s XGBoost model into FastAPI and used SHAP to explain how attendance, grades, assignments, and LMS activity contributed to each prediction. The model reached **98.59% accuracy on a 10,000-record internal holdout**. The app also connects faculty follow-ups to Google Calendar through n8n.

`XGBoost` `SHAP` `FastAPI` `PostgreSQL` `n8n`

### [SkyBridge](https://github.com/DhyanMehta/SkyBridge) · Flight disruption recovery

Built this solo MVP for the 22North Product Engineering Challenge 2026. Python rules decide whether to rebook, refund, wait, or escalate. A LangGraph workflow uses an LLM to explain the decision to the passenger.

`Python` `LangGraph` `Groq` `FastAPI` `React`

### SHM Insurance · AI-assisted policy intake

Built a document intake workflow that uses Groq to extract eight fields from policy PDFs, match insurer names, and let an agent review the extracted data before saving it.

`Groq` `TypeScript` `Express` `PostgreSQL` `Cloudflare R2`
